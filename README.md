# 🐝 BeeStock

**BeeStock** es una aplicación web pensada para ayudarte a gestionar el stock de medicamentos de forma clara, visual y colaborativa. Ideal para clínicas, farmacias o usuarios que necesitan llevar control de sus tratamientos.

---

## 🚀 Características

- 📦 Visualización de stock con tabla y gráfico de barras
- 🧑‍💻 Acceso por usuario y contraseña con roles (admin, invitado)
- ⏰ Recordatorios de toma con horarios y frecuencia
- 📱 Interfaz adaptable para uso desde el teléfono
- 🧠 Navegación fluida con React Router y Material UI

---

## 🛠️ Tecnologías

- [React](https://reactjs.org/)
- [Material UI](https://mui.com/)
- [Chart.js](https://www.chartjs.org/)
- React Router DOM
- LocalStorage (para persistencia básica)
